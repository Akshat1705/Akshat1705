## About Me

Hi, I'm **Akshat** 👋

Final-year B.Tech (Information & Communication Technology) student at **Pandit Deendayal Energy University**, building toward a career as a **Software Development Engineer**.

* 🔭 Currently building backend systems with **Java, Spring Boot, PostgreSQL, and Redis** — my latest project is a URL shortener with async analytics, Base62 encoding, and rate limiting.
* 🧠 Solved **170+ problems on LeetCode**, with a focus on arrays and strings.
* 💼 Previously interned at **Delpat LLP**, where I built an end-to-end Speech-to-Text (ASR) system in PyTorch, reducing Word Error Rate by **53%**.
* ⚙️ Also comfortable across the full stack — built **ErrandMate**, a cloud-native task marketplace on AWS with Docker.
* 🌱 Currently sharpening system design fundamentals — caching strategies, async processing, and distributed system trade-offs.
